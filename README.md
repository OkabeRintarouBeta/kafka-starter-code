## Summary
This repo contains the code for building
1. A simple producer-consumer example using Kafka Java Client following [tutorial](https://developer.confluent.io/get-started/java/)
2. A target word count stream processing example using Kafka Stream API, in two forms
   1. [Streams DSL tutorial](https://kafka.apache.org/40/documentation/streams/tutorial)
   2. [Processor API tutorial](https://kafka.apache.org/documentation/streams/developer-guide/processor-api.html)
